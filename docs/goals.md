# /goal で自律的に作業するときの規則

開発者が仕事をしている間、Claude Code の `/goal` で各 WS を自律的に進める。本書はその規則と雛形。

## 1. /goal の性質（前提）

- 各ターンの終わりに小型モデルが条件を満たしたかを判定し、満たしていなければ次のターンが始まる
- **判定役はファイルを読まずコマンドも実行しない。** 会話に表れた出力だけで判定する。条件は、コマンドの実行結果で証明できる形で書く
- 無人で回すには auto mode で実行する
- 1セッションに1ゴール。WS ごとに worktree とセッションを分ける

## 2. 条件の書き方

条件には必ず次の4つを含める。

1. **終了状態:** `docs/roadmap.md` の完了条件、または具体的な機能の完成
2. **証明方法:** どのコマンドが exit 0 になればよいか
3. **制約:** 途中で変えてはいけないもの
4. **上限:** 「または N ターンで停止し、残課題を `docs/progress.md` に書く」

すべての条件に、共通の証明として `pnpm guard` の exit 0 を含める。

## 3. 守らせる制約（すべてのゴールに共通）

- `knowledge/` と `scenarios/` を作成・変更しない（フックでも遮断される）
- テストを削除・skip・弱めて通さない
- 担当 WS のディレクトリ以外を変更する場合は、理由を `docs/progress.md` に書く
- 各ターンの終わりに `docs/progress.md` へ追記する

## 4. 雛形

### 機能を完成させる

```
/goal docs/roadmap.md の <マイルストーン> のうち <WS名> の担当範囲を完了する。
証明: `pnpm typecheck && pnpm test && pnpm guard` が exit 0。<追加の証明があれば書く>
制約: knowledge/ と scenarios/ を変更しない。テストを削除・skip しない。担当ディレクトリ以外を変更しない。
各ターンの作業内容を docs/progress.md に追記する。
<N> ターンで停止し、残課題を docs/progress.md に書く。
```

### 例: M1 の一気通貫

```
/goal docs/roadmap.md の M1 を完了する。
証明: `pnpm typecheck && pnpm test && pnpm guard` が exit 0 で、
`pnpm test:e2e -- --grep <シナリオid>` でそのシナリオのリプレイが最後まで通ること。
このテストは、各観測の後に結論と分岐点が更新されることを検証していること。
制約: knowledge/ と scenarios/ を変更しない。テストを削除・skip しない。
各ターンの作業内容を docs/progress.md に追記する。
40 ターンで停止し、残課題を docs/progress.md に書く。
```

### 例: シナリオの振る舞いをすべて通す

```
/goal すべてのシナリオの expectations を満たす。
証明: `pnpm test:e2e && pnpm guard` が exit 0。
改善してよいのは apps/agent のプロンプト・ツール、packages/core の計算のみ。
シナリオ id や期待値をコード・プロンプトに埋め込まない。
制約: knowledge/ と scenarios/ を変更しない。テストを削除・skip しない。
各ターンの作業内容を docs/progress.md に追記する。
30 ターンで停止し、残課題を docs/progress.md に書く。
```

## 5. ゴールに向かないもの

- **見た目の良さ:** 判定役は画面を見られない。Playwright のテストが通るところまでをゴールにし、見た目は開発者が確認する
- **判断が現場の感覚に合っているか:** 開発者が確認する
- **知見ナレッジやシナリオの追加:** 開発者が書く

## 6. 1日の回し方

| 時間帯 | やること |
|---|---|
| 朝（出勤前） | WS ごとに worktree を分け、2〜4本のセッションでゴールを設定する |
| 昼休み | スマートフォンから進捗を確認する。止まっていれば方針を伝える |
| 夜 | 差分と `docs/progress.md` を確認し、画面を実際に触る。「開発者に確認したいこと」に答え、知見ナレッジとシナリオを追記し、翌日のゴールを決める |

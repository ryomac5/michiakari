# 運転整理

## 要点

### 定義

運転整理は、乱れたダイヤを一時的に変えて平常に戻す作業である。
JR西日本は、再開の前の段階を輸送手配と呼んでいる。
この段階で、指令は列車の運転順序と運転区間を整えて各列車に指示する。

### 手段

| 手段 | 内容 |
| --- | --- |
| 抑止 | 後の予定を決めずに列車を止めておく。不通区間へ向かう列車は、駅間で止まらないよう手前の駅で止める |
| 通知運転 | 前の列車が次の駅の番線を空けるまで、後ろの列車を出さない |
| 時間調整 | 遅れた列車の前後の発車を遅らせ、間隔をそろえる。団子運転を防ぐためである |
| 運転休止 | 列車を始発から走らせない。遅れは回復するが、運べる人数が減る |
| 運転打ち切り | 途中の駅で運行をやめる。部分運休とも呼ぶ |
| 折り返し運転 | 走れる区間だけで列車を往復させる。不通区間の手前の駅で折り返す |
| 種別変更 | 主に特急を急行にするように格下げする |
| 臨時停車 | 通過駅に止める。臨時の通過は誤乗を招くため避けられる傾向がある |
| 運行順序変更 | 先に出る列車と後に出る列車を入れ替える |
| 運転線路変更 | 複々線で列車線と電車線を入れ替え、遅れの波及を防ぐ |
| 段落とし | ある列車を運休し、その車両を後ろの列車に充てる |
| 計画運休 | 台風など予測できる天災に備え、運休の時間を前もって知らせる |

間引き運転を独立に定義した公的な資料は見つからなかった。
運転休止を間隔を空けて繰り返すと、利用者からは間引きに見える。

### 運休と遅れの釣り合い

運転整理の研究は、部分運休と遅れを釣り合わせる問題として扱っている。
運休を多く許すと、ダイヤは早く元に戻る。
運休を避けると、遅れの合計が大きくなる。
現場では、ダイヤの修正は人手が中心の作業だと紹介されている。

## 利用者から見える兆候

| 手段 | 兆候 |
| --- | --- |
| 抑止 | 駅で発車しないまま止まっている。放送は、しばらく停車すると伝える |
| 運転打ち切り | 行先の途中の駅で、この列車は運転を取りやめると伝えられる |
| 折り返し運転 | 案内に、駅名と駅名の間で折り返し運転と出る |
| 行先変更 | 発車標の行先が、ふだんより手前の駅に変わる |
| 種別変更 | 特急や急行が、各駅に止まると案内される |
| 運転休止 | 発車標から列車が消える。次の列車まで間隔が空く |
| 順序変更 | 後の列車が先に発車すると案内される |

## アプリへの使い道

- 折り返し運転の案内は、走れる区間がはっきりした合図になる
- 折り返しの手前の駅までは、待たずに列車で進める
- 抑止で駅にいる列車は、駅で降りて他の手段に移れる
- 運転打ち切りの案内は、その先へ向かう利用者に乗り換えを促す合図になる
- 行先の変更は、利用者の行き先が範囲内かを判定するのに使える
- これらの言い回しは、`ANNOUNCEMENT_CUE_PATTERNS` の新しい手がかりにできる

# 気象による規制

## 要点

### 共通の流れ

JR西日本は、風、雨、地震の規制を同じ形の手順で説明している。

| 順 | 内容 |
| --- | --- |
| 1 | 計器の値が規制値に達し、指令所のブザーが鳴る |
| 2 | 指令が必要な区間の列車を徐行させるか、見合わせる |
| 3 | 値が規制値を下回る |
| 4 | 保守の係員が線路や設備を点検する |
| 5 | 指令が運転順序と運転区間を整え、再開を指示する |
| 6 | 正常ダイヤへ戻す。再開の後も徐行することがある |

値が下がっても、点検が終わるまで再開しない。
この順番が、雨や風が止んでも動かない理由である。

### 強風

JR西日本は、風速が規制値に達すると徐行か見合わせを行う。
一部の線区では見合わせでなく徐行にとどめる。
風が収まった後も、突風に備えて一定の時間は見合わせを続けることがある。
規制値を下回った後は、飛来物や倒木の点検を指示することがある。

公表されている数値は次のとおりである。

| 項目 | 公表値 | 出典 |
| --- | --- | --- |
| 防風柵のある規制区間の見合わせの規制値 | 25m/s から 30m/s に緩和 | JR西日本 |
| 防風柵による見合わせ時間 | おおむね 3 分の 1 以下になる見込み | JR西日本 |
| 防風柵の整備の対象 | 平成 20 年から湖西線と北陸線 | JR西日本 |
| 東海道線の風速計の規制値の例 | 25m/s | JR東海 |

JR東海の例では、1 か所の風速計で 12.1km の区間を止めた。
このときは約 2 時間半の見合わせの後に再開した。
風速計 1 か所が、前後の広い区間の運転を左右することが分かる。

### 大雨

雨量の規制には、短い時間の強い雨と、長く続いた雨の 2 種類がある。
河川の水面から橋桁までの高さが規制値に達したときも、徐行か見合わせを行う。
雨が止んでも、斜面や線路が水を含んでいれば崩れる恐れがある。
このため、天気が回復しても徐行や見合わせを続けることがある。
JR西日本は、盛土や自然の斜面が多く、運行の範囲も広いと説明している。
そのため再開まで時間がかかることがあるとしている。
点検は、徒歩の巡回、線路の確認、土砂の撤去、土のうの設置、橋梁の確認である。

関西の事業者の雨量の規制値は、公表されたものが見つからなかった。
他の地域では、時間雨量と連続雨量を組み合わせる方式が公表されている。
JR東海は在来線の雨量計を 147 か所に置いていると公表している。
JR東海は 2020 年に、在来線へ土壌雨量による規制を導入すると発表した。
JR東日本は、半減期の違う実効雨量を組み合わせる方式を導入している。

### 地震

地震計の値が規制値に達すると、列車を緊急に止める。
乗務員が揺れを感じたときも、ただちに止める。
その後、状況に応じて徐行か見合わせを行う。
震度に応じて、点検が必要な箇所を確かめる。
点検の範囲が広いか、設備に被害があれば、再開まで時間がかかる。
駅間を歩いて巡回する場合は、再開まで時間がかかる。

JR西日本は京阪神で、規制区間別路線図を使っている。
乗務員は自分の列車の規制のレベルを確かめ、定められた扱いをとる。
DISER という仕組みで、500m ごとの推定震度を受け取っている。
次の駅まで動ける列車を見分け、駅間での降車を減らすためである。
阪急電鉄も、安全を確かめた区間は徐行で最寄りの駅まで進む扱いに改めた。

関西の事業者の地震の規制値は、公表されたものが見つからなかった。

### 計画運休

台風のように予測できる天災では、前もって運休を知らせる。
国土交通省は 2019 年に、計画運休の情報提供の取りまとめを公表した。
モデルケースは、可能性の発表を 48 時間前の例として示している。
詳しい計画の発表は、24 時間前の例として示している。
強風の後の再開では、基本的に全線で構造物と飛来物を確かめる必要がある。
計画運休のときは、振替輸送が行われない場合もある。
発表には、次のお知らせの予定時刻を添えることが望ましいとされる。

## 利用者から見える兆候

- 運行情報に、雨量計や風速計の値が規制値を超えたと出る
- 雨や風が止んでも、点検中と案内される
- 運転を再開しても、徐行のため遅れると案内される
- 地震の直後は、自分の路線の全区間が止まる
- 地震の後、揺れの小さい区間の列車から駅まで進む
- 台風の前日までに、運休の可能性が発表される

## アプリへの使い道

- 天気の事象は、値の低下でなく点検の終わりで再開とみなす
- 雨は、止んだ後もしばらく見込みを短くしない
- 風は、収まった直後でも一定の時間は再開を見込まない
- 湖西線と北陸線の防風柵の区間は、他より見合わせが短い傾向に寄せられる
- 地震では、揺れの小さい区間の列車が先に次の駅へ着く
- 計画運休の発表は、次のお知らせの時刻を画面に出す材料になる
- 規制値の数値そのものは、判断に使わない

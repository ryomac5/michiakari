# 駅間で止まった列車

## 要点

### 救済の 3 つの方法

| 方法 | 内容 |
| --- | --- |
| 自力で駅へ | 安全を確かめた区間を、徐行で次の駅まで進む |
| 救援列車 | 別の列車をつないで駅まで押すか引く。隣の線路に並べ、渡り板で乗り移る方法もある |
| 線路へ降りる | はしごなどで線路に降り、近くの駅や踏切まで歩く |

### 駅へ進む扱い

列車を駅まで進められれば、利用者は駅で降りられる。
JR西日本は京阪神で、地震の後に次の駅まで動ける列車を見分けている。
阪急電鉄は大阪北部地震の反省から、安全を確かめた区間は徐行で最寄りの駅へ進む扱いに改めた。
事業者は、できるだけ駅で降ろせるよう対策を進めていると報じられている。

### 救援列車

自力で動けない列車には、救援の列車を向かわせる。
救援の列車をつないで、押すか引いて駅まで運ぶ。
隣の線路に救援の列車を並べ、渡り板で乗り移る方法もある。
乗り移る方法では、扉の位置を合わせる作業が要る。
カーブや勾配があると、扉の位置がずれやすい。
救援の列車が着くまで、利用者は車内で待つ。

### 線路へ降りる判断

事業者は、復旧の見通しと車内の状況を合わせて降車の必要を決める。
降車を始めると、作業を優先するため再開が遅れる。
国土交通省は、再開の見込みを示すことも難しくなるとしている。
線路に降ろすには、線路を安全な状態にする必要がある。
再開の前には、線路に人が残っていないかを確かめる必要がある。
短い時間で回復できるなら、降ろすとかえって再開が遅れる。
猛暑の停電で空調が止まると、より早く降車を決める必要がある。

### 大阪北部地震の記録

2018 年 6 月 18 日の 7 時 58 分に地震が起きた。
国土交通省によると、関西で 245 本の列車が駅間で止まった。
救済した乗客は約 21 万人である。
救済に時間がかかったことが課題になった。
国土交通省は、その後に降車誘導を早める対応例を取りまとめた。

| 対応例 | 内容 |
| --- | --- |
| 応援の要請 | 乗り合わせた鉄道関係者や乗客に、降車の手伝いを頼む |
| 早い開始 | 駅や踏切が近く乗務員だけで安全を保てれば、応援を待たずに始める |
| 設備の配備 | 編成の長さに応じて、はしごや照明を車両や駅に置く |
| 訓練 | 乗客の協力を得る場合も含め、定期的に訓練する |

## 利用者から見える兆候

- 放送で、救援の列車を手配していると伝えられる
- 放送で、線路に降りて歩いて避難すると伝えられる
- 係員がはしごや照明を持って車内に来る
- 隣の線路に別の列車が止まる
- 停電で空調と照明が止まる
- 徐行で動き出し、次の駅で止まる

## アプリへの使い道

- `rescue` の手がかりは、長く止まる見込みに寄せる根拠になる
- 降車の案内が出たら、再開の見込みを出さない根拠になる
- 降車の案内は、新しい手がかりの id にできる
- 徐行で動き出したら、次の駅で降りて切り替える選択肢を示せる
- 地震の後は、次の駅へ進める列車と進めない列車を分けて示せる
- 猛暑の停電は、体調を優先する案内に切り替える合図になる

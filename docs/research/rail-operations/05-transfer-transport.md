# 振替輸送

## 要点

### 定義

振替輸送は、止まった区間を含む乗車券で、他社の線に乗れる扱いである。
運賃を追加で払わずに乗れる。
事業者どうしの連絡運輸の取り決めに基づく。
取り決めの無い相手には適用されない。
代行輸送は、事業者が用意するバスなどの手段である。
代行輸送には決まった規則が無い。

### 始まる条件

京阪電鉄は、災害や事故で運行に支障が出て、復旧に時間がかかると判断したときに行うと説明している。
実施の有無と範囲は状況で変わり、駅や運行情報で案内される。
国土交通省は、振替輸送の有無を運べる人数などの事情で決めるとしている。
計画運休のときは、振替輸送が行われない場合もある。
国土交通省は、行わない場合も含めて案内することが重要だとしている。

### 関西の共通の扱い

2019 年 3 月 16 日から、関西の 18 の事業者が振替輸送の使い方を改めた。
JR西日本、阪急、阪神、京阪、近鉄、南海、Osaka Metro などが含まれる。

| 項目 | 内容 |
| --- | --- |
| 振替乗車票 | 配らずに、対象の乗車券を見せて乗る |
| 乗り換える駅 | 対象の乗車券の区間内なら、利用者が選べる |
| IC カード | 改札に入った後の IC 乗車券は対象外になる |
| 例外 | バスとの振替と、近鉄の東海の地域は振替乗車票を配る |

京都市交通局の規程も、IC 定期券を除く入場後の IC を対象外とした。

### 対象になる乗車券

京阪電鉄の案内を例に挙げる。

| 種類 | 扱い |
| --- | --- |
| 普通乗車券 | 運行できなくなる前に買い、止まった区間を含むものが対象 |
| 定期券 | 券面の区間に止まった区間を含むものが対象。磁気と IC の両方 |
| 回数券と企画券 | 運行できなくなる前に入場し、止まった区間を含むものが対象 |
| QR の乗車券 | 運行できなくなる前に使い始め、止まった区間を含むものが対象 |
| IC カードの残額 | 対象外。PiTaPa と ICOCA を含む |
| 止まった後の乗車券 | 止まった後に買ったものや入場したものは対象外 |

### 使い方

係員に乗車券を見せて、振替先の線に乗る。
自動改札に IC 定期券を当てると、残額から運賃が引かれる。
振替の区間の外を通る経路やタクシーの費用は、利用者の負担になる。
振替の区間の途中で改札を出ると、その区間の運賃がかかる。

## 利用者から見える兆候

- 運行情報に、振替輸送を実施中と出る
- 改札の近くに、振替先の線と駅の案内が掲示される
- 計画運休の発表に、振替輸送を行わないと書かれる
- 振替先の線が混み、入場を規制することがある

## アプリへの使い道

- 振替の選択肢は、利用者の乗車券の種類で費用が変わる
- IC の残額で入場した利用者には、振替先の運賃がかかると示す
- 定期券ときっぷの利用者には、振替先の運賃を 0 円にできる
- 乗り換える駅は、区間内なら利用者が選べるので、近い駅を勧められる
- 振替の実施は発表を見て決まるので、未発表なら費用を両方示す
- 計画運休では、振替が無い前提で他の手段を並べる

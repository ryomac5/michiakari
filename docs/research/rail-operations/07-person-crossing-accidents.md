# 人身事故と踏切事故の後の流れ

## 要点

### 人身事故の手順

JR西日本は、列車が人と接触した後の手順を 6 つに分けて公表している。

| 順 | 内容 |
| --- | --- |
| 1 | 運転士が列車を止め、周りの列車を緊急に止める信号を出す。指令に連絡し、乗客の安全を確かめる |
| 2 | 救出に関わらない列車は、確かめが済み次第、指令が再開を指示する。当該の列車と後続の列車は止めたままにする |
| 3 | 消防が負傷者を救出する。警察が現場検証と関係者への聞き取りを行い、遺留品を探す |
| 4 | 消防、警察、係員が全員線路の外へ出たことを確かめる |
| 5 | 指令が運転順序と運転区間を整え、再開を指示する |
| 6 | 正常ダイヤへ戻す |

夜間は、救出と遺留品の捜索にさらに時間がかかることがある。
朝夕のラッシュ時は、正常ダイヤに戻るまで時間がかかる。
隣の線路を確かめることも、再開の前の手続きに含まれる。
東武鉄道も、ほぼ同じ手順を公表している。
東武鉄道は、鉄道側が車両、線路、架線、踏切を点検すると説明している。

### 再開の順番

最初に動くのは、救出に関わらない列車である。
当該の列車と後続の列車は、最後まで止まる。
現場の作業が終わっても、全員の退出を確かめるまで動かない。

### 踏切事故

踏切で自動車と衝突した後も、救出と現場検証の流れは同じである。
東武鉄道は、動けなくなった車両をレッカー車で運び出すと説明している。
東武鉄道は、復旧の後に状況に応じて試運転で安全を確かめると説明している。

### 踏切の防護

JR西日本の踏切には、取り残された自動車を見つける障害物検知装置がある。
踏切の非常ボタンを押すと、特殊信号発光機が光って乗務員に知らせる。

## 利用者から見える兆候

- 放送で、人身事故や踏切での事故と伝えられる
- 反対の線路の列車が先に動き出す
- 現場に警察と消防の車両が集まる
- 運行情報に、現場検証や車両点検と出る
- 運行情報に、再開の見込み時刻が出る

## アプリへの使い道

- 反対の線路が先に動くことは、`estimateUnaffectedTrackResume` の公開の根拠になる
- 当該と後続が最後まで止まることは、`queued_behind` の理由の根拠になる
- 夜間の発生は、見込みを長めに寄せる手がかりにできる
- ラッシュ時の発生は、正常ダイヤまでが長い見込みに寄せられる
- 脱線を伴う踏切事故は、`very_long` の見込みの根拠になる
- 現場検証の段階の案内は、新しい手がかりの id にできる

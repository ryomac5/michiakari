# 輸送障害時の運転の仕組みの調査

調査日は 2026-11-07 である。
公開資料から、輸送障害のときの運転の仕組みを集めた。
出典は国土交通省、事業者の一般向けの説明、学術資料、百科事典、報道に限る。
社内規程と内部の数値は使っていない。
本文はすべて要約であり、原文を写していない。
数値は出典に書かれた公表値だけを載せる。

## 読み方

各ファイルは同じ 4 節で書く。
要点、利用者から見える兆候、アプリへの使い道、出典である。
アプリへの使い道は、`docs/architecture.md` の 4.1 節の規則表と手がかりの id に合わせて書いた。

## 出典が見つからなかったもの

- 関西の事業者が公表した雨量と地震の規制値は見つからなかった
- 人身事故の再開までの時間について、公的な平均値は見つからなかった
- 間引き運転の公的な定義は見つからなかった
- 関西の相互直通運転で直通を止める基準は、公式の説明が見つからなかった
- 防護無線の解除の手順は、百科事典の記述しか見つからなかった
- 救援列車による救済の所要時間は、公表値が見つからなかった
- 阪急、近鉄、Osaka Metro、JR西日本の各社単独の振替輸送の案内ページは、取得できなかった

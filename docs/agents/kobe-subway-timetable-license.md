# 神戸市営地下鉄の時刻表データのライセンス確認

確認日は 2026-11-05 である。対象は神戸市営地下鉄の時刻表と駅所在地のデータである。

## 結論

## 判断の要点

- 神戸市営地下鉄の時刻表は交通局が CC BY 2.1 JP で公開する。各社の時刻表を使わない理由である「一括での再利用の許諾がない」は、この路線には当たらない。
- 公共交通オープンデータセンターに神戸市営地下鉄はない。同センターの基本ライセンスは再配布を禁じるので、仮にあっても公開リポジトリには置けない。
- GTFS 形式の公式提供はない。CSV から自前で変換する。
- CC BY 2.1 JP は旧版である。creativecommons.org は新規の利用に 4.0 を勧めるが、提供元が 2.1 JP を指定しているので従う。

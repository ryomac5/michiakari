## 機能

- 判断のあとに端末の戻るで 1 段戻れるかを、実機で確かめる。手順は docs/progress.md の T4 にある
- 判断の画面を 3 段に分け、同じ情報の繰り返しをなくす。開発者の判断を待っている
- 選択肢の一覧で選んだ経路を、地図に描き直す。いまは地図の札から一覧への一方向だけである
- 地図の描き方を整える。関係のない路線を細く薄くし、徒歩の直線を消す
- 必須の札を画面内に重ならずに置けない極端な場面で、札が画面の外に少しはみ出す。実際の画面では起きていない

## 開発者にしかできないこと

- 本物の知見とシナリオを knowledge/ と scenarios/ に書く
- API キーを入れて pnpm smoke:claude を流し、claude モードを確かめる
- docs/guides/deploy.html の手順で公開する
- docs/progress.md の「開発者に確認したいこと」に答える。主な項目は次のとおり
  - 詰める動き、着けるホームの表、運転パターンの仮の値
  - 徒歩の上限の 15 分と 25 分
  - 時刻だけ聞こえた場合の幅の 10 分と、確信度の「中」
  - 結末のカードで比べる相手
  - 提出動画の色

# 製品仕様（vision）

## 作った理由

事故が起きると、現場はまず安全の確保と復旧に手を取られます。
そのため、お客様への案内は「何が起きたか」で止まりがちです。
一方で、運転士や指令員の経験があれば、この先の流れはある程度読めます。
たとえば人身事故なら、警察と消防の確認を経るので、再開まで 1 時間前後かかります。
車内の非常通報なら、5〜10 分ほどで動き出すことが多く、慌てなくて大丈夫です。
その読みを、いま困っている人の手元へ自動で届けたい。
いま取れる選択肢を知り、自分で決められるようにするためです。

## 1. 一文での定義

輸送障害に遭遇した鉄道利用者に、指令員の知見をもとに、いま取れる選択肢と、その見込みを示すWebアプリ。

## 2. 解決する問題

運行情報は「運転見合わせ」「振替輸送実施中」といった事実を伝える。しかし利用者が本当に知りたいのは次のことである。

- いつ頃再開しそうか
- 待つべきか、別の手段に切り替えるべきか
- 切り替えるなら、どこへ歩けば何に乗れるのか
- 終電や約束の時刻に間に合うのか

指令の内部では、事象の性質と経過からおおよその復旧見込みを立てている。その判断材料が利用者に届いていない。この情報の差を埋める。

## 3. 判断の作り方

本アプリは、元指令員の経験を外から観察できる兆候の規則に落としている。知見そのものは公開しない開発の材料で、アプリは規則表と報道の統計値で判断する。

## 4. 対象

**利用者：** 関西の鉄道利用者すべて。毎日の通勤客も、土地勘のない旅行者・訪日客・高齢者も含む。

属性ではなく、その時の**状況**に合わせて出力を変える。

- 現在地と行き先
- 時間の制約（終電、約束、乗り継ぎ）
- 代替経路の知識の有無
- 移動の制約（荷物、体力、子ども連れ）
- 費用の許容度

**対象エリア：** 京阪神と、そこにつながる奈良・大津・和歌山の都市圏。範囲は設定値（ポリゴン）として持ち、範囲内の全鉄道路線を国土数値情報から自動抽出する。

**主軸の事業者：** JR西日本（京阪神エリア）、阪急、阪神、Osaka Metro、南海。範囲内のその他の事業者（京阪、近鉄、北大阪急行、大阪モノレール、山陽、神戸市営地下鉄など）も振替先・乗り換え先としてすべて含める。

## 5. 返す価値

アプリが返すのは次の3つ。

1. **見込み：** 再開までの残り時間の推定。幅を持たせて示し、事象の段階の説明は出さない
2. **分岐点：** 「◯時◯分までに再開しなければ、振替のほうが早く着く」という判断の境目
3. **行動：** 状況に合わせた具体的な行動。代替経路を知っている人には分岐点だけ、知らない人には道順まで示す

すべての判断に、使った手がかりと規則を根拠として付ける。

## 6. 利用の流れ

1. **始める：** 現在地を取得するか駅を選ぶ。行き先を入力する
2. **状況を伝える：** 掲示や画面を撮影する／発表文を貼り付ける／事象と聞こえた案内を選択式で答える
3. **判断を受け取る：** 結論、分岐点、地図、根拠（開いたときのみ）
4. **変化を追う：** 新しい情報を追加すると判断が更新される。分岐点が近づくとアプリ内で知らせる
5. **行動する：** 選んだ選択肢の道順を地図に示す。振替輸送の利用条件も説明する

## 7. エージェントの振る舞い

- 判断の主体はエージェント。事象の振る舞いの規則表、報道の統計値、気象、代替手段、時間の制約を判断材料として参照する
- 判断には必ず根拠を付ける
- 数値（分岐点、到着時刻、運賃）はコードで計算し、エージェントはその結果を解釈して言葉にする
- 確信が持てないときは見込みを断言せず、分岐点を中心に示す
- 公式発表と食い違う推定を出すときは、推定であることを明示する

## 8. 確定事項

| 項目 | 決定 |
|---|---|
| 言語 | 日本語と英語。中国語・韓国語は拡張候補 |
| 会員登録 | なし |
| 現在地 | 判断に必要な範囲でのみサーバーに送り、保存しない |
| 注意書き | 結論の近くに「推定であり、公式発表を優先してください」を常時表示 |
| 運行情報の取得 | 利用者が持ち込む。事業者のデータを自動取得しない |

## 9. 作らないもの

- 運行情報・列車走行位置の自動取得
- 会員登録、履歴の保存
- 乗車券の購入・予約
- プッシュ通知（運行情報を自動取得しないため）

## 10. 審査基準との対応

審査基準の全文は `docs/judging-criteria.md` にある。

| 審査基準 | 評価を取る要素 |
|---|---|
| インパクト（30%） | 誰もが経験する場面。終電間際や土地勘のない人ほど価値が大きい。テーマ1（あなたにしかない深さ）とテーマ2（誰にでも届くべきもの）の両方に該当 |
| デモ（25%） | 発表が更新されるたびに判断と地図が変わる様子をリプレイで見せる |
| Claude の活用（25%） | 写真・文章の解釈、規則表と統計値を参照した推論、状況に合わせた説明、推論過程のストリーミング |
| 深さと実行（20%） | 元指令員の経験を落とした事象の振る舞いの規則表。判断に使った手がかりと規則を、根拠として画面に示す |

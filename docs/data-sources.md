# データソース

このファイルに記載のないデータは使わない。新しいデータ源を使う場合は、ライセンスを確認してから追記する。

## 1. 使用するデータ

| 用途 | データ | 提供元 | 利用条件 | 状態 |
|---|---|---|---|---|
| 路線・駅 | 国土数値情報（鉄道） | 国土交通省 | ダウンロードページの利用条件に従う。出典表示が必要 | 利用条件の確認が必要 |
| 駅の規模（混雑の目安） | 国土数値情報（駅別乗降客数） | 国土交通省 | 同上 | 利用条件の確認が必要 |
| 背景地図 | 地理院タイル | 国土地理院 | 出典表示で利用可 | 利用可 |
| 道路網・駅出入口 | OpenStreetMap | OpenStreetMap contributors | ODbL。出典表示が必要 | 利用可 |
| 徒歩経路・到達範囲 | Valhalla による計算結果 | 自前（OSM から計算） | 元データの ODbL に従う | 利用可 |
| 雨量・警報 | 気象庁（アメダス、警報・注意報） | 気象庁 | 気象庁ホームページの利用規約に従う。出典表示が必要 | 利用可 |
| タクシー運賃 | 公示運賃体系 | 近畿運輸局 | 事実情報として計算式を実装 | 利用可 |
| 路線種別ごとの速度・運転間隔 | 自作パラメータ | 開発者の推定 | 自作 | 作成予定 |
| 振替輸送の対象路線・利用条件 | 自作の定義 | 開発者が一般的な仕組みとして記述 | 自作。各社の文面を転載しない | 作成予定 |
| 知見ナレッジ | 自作 | 開発者の実務経験を一般化 | 自作。社内規程・数値は含まない | 作成予定 |
| シナリオ | 自作の架空データ | 開発者 | 自作 | 作成予定 |

## 2. 使用しないデータ

| データ | 理由 |
|---|---|
| 各社の運行情報ページ・アプリ | 二次利用の許諾がない。Osaka Metro は無許可の二次利用を明示的に禁止 |
| 列車走行位置サービス | 再利用の許諾・API が確認できない |
| 非公式 API・スクレイピング | 権利が確認できない |
| 各社の時刻表 | 一括での再利用の許諾が確認できない |
| 各社のラインマーク・ロゴ | 商標の可能性。路線の色のみ使用する |
| 公共交通オープンデータチャレンジ限定のデータ | 同チャレンジ以外での利用不可 |
| 社内情報 | 規制値、規程、内部手順、実際の事故記録 |

## 3. 前処理上の注意

- 国土数値情報の版によっては、新しい駅（うめきた地下の大阪駅など）や事業者の変更（2025年4月の泉北高速鉄道の南海への合併）が反映されていない。使用する版を確認し、必要に応じて正規化する
- 鉄道データは駅も線で表現されている。駅の代表点は線の中点などで求める
- アメダスの10分値は気象庁のサイトで約9日分しか公開されない。デモ用に必要な期間がある場合は、取得した値を保存する

## 4. 出典表示

画面の地図の隅と、アプリ内の「このアプリについて」に以下を表示する。

```
地図: 国土地理院 / © OpenStreetMap contributors
鉄道データ: 国土数値情報（鉄道データ）（国土交通省）を加工して作成
気象データ: 気象庁
```

## 5. 未確定事項

- 終電時刻: オープンなデータがない。利用者が時間の制約として入力する方式を基本とし、別の方法があれば検討する
- バス: GTFS データリポジトリに関西の事業者が登録されているか確認する。なければ対象外とする

# データソース

このファイルに記載のないデータは使わない。新しいデータ源を使う場合は、ライセンスを確認してから追記する。

## 1. 使用するデータ

| 用途 | データ | 提供元 | 利用条件 | 状態 |
|---|---|---|---|---|
| 路線・駅 | 国土数値情報（鉄道） | 国土交通省 | 2025年度版はオープンデータ CC BY 4.0 で、加工・再配布・商用利用ができる。出典と加工した旨の記載が必要 | 利用可 |
| 駅の規模（混雑の目安） | 国土数値情報（駅別乗降客数） | 国土交通省 | 2024年度版はオープンデータ CC BY 4.0 で、条件は鉄道と同じ | 利用可 |
| バス停の確認先 | 国土数値情報 P11 の 2022 年度版 | 国土交通省 | CC BY 4.0。出典、元ページ、加工した旨を表示し、時刻と運行可否は出さない | 採用候補 |
| 背景地図 | 地理院タイル | 国土地理院 | 出典表示で利用可 | 利用可 |
| 道路網・駅出入口 | OpenStreetMap | OpenStreetMap contributors | ODbL で出典表示が必要。前処理に Geofabrik の関西抽出の pbf を使い、版は 2026-11-01 である | 利用可 |
| 徒歩経路・到達範囲 | Valhalla による計算結果 | 自前（OSM から計算） | 元データの ODbL に従う。乗換の徒歩時間と主要 300 か所の到達範囲を事前に計算し、公開環境では Valhalla を動かさない | 利用可 |
| 地名・施設名の座標変換 | Nominatim の検索結果 | OpenStreetMap Foundation | 公開インスタンスの利用ポリシーに従う。サーバー側から毎秒1件以下で呼び、結果をキャッシュし、入力補完には使わない | 利用可 |
| 雨量・警報 | 気象庁（アメダス、警報・注意報） | 気象庁 | 気象庁ホームページの利用規約に従う。出典表示が必要 | 利用可 |
| タクシー運賃 | 公示運賃体系 | 近畿運輸局 | 事実情報として計算式を実装 | 利用可 |
| 路線種別ごとの速度・運転間隔 | 自作パラメータ | 開発者の推定（仮） | 自作。置き場所は packages/core/params | 作成済み |
| 振替輸送の対象路線・利用条件 | 自作の定義 | 開発者が一般的な仕組みとして記述 | 自作。各社の文面を転載しない | 作成予定 |
| 運転見合わせの所要時間の統計値 | 公開の報道と鉄道会社の発表から集計した所要時間の統計値。個々の事例は docs/research にある | 開発者が調査し集計 | 自作の集計。本文は転載せず、事実と出典 URL のみ | 作成済み |
| 事象の振る舞いの規則表 | 自作 | 開発者の実務経験を規則に落とす | 自作。知見の材料は公開せず、社内規程・数値は含まない | 作成予定 |
| シナリオ | 自作の架空データ | 開発者 | 自作 | 作成予定 |

注: 以下の一次情報は 2026-11-02 に確認した。

- 国土数値情報の利用規約: https://nlftp.mlit.go.jp/ksj/other/agreement.html 。2026年3月23日から公共データ利用規約第1.0版が適用される。複製、公衆送信、加工した成果の公開ができる
- 鉄道: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html 。最新は2025年度版で、データ基準日は2025年12月31日。2020年以降の版が CC BY 4.0 である
- 駅別乗降客数: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2024.html 。最新は2024年度版で、2026年4月に公開された。元資料は1年前の統計である
- バス停留所: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11-2022.html 。2026-11-05 に確認した。2022年度版は CC BY 4.0 である。2010年度版は非商用なので使わない。関西 6 府県の府県別の SHP 版の zip を取得し、中の GeoJSON を読む。詳細は `docs/agents/bus-data.md` にある
- 泉北高速鉄道の合併とうめきたの大阪駅は、ともに鉄道2025年度版の基準日より前の変更である。作成方法には基準日までの開通と駅の新設を反映すると書かれている。実データでの反映は未確認で、WS1 の前処理で確かめる
- Nominatim: https://operations.osmfoundation.org/policies/nominatim/ 。上限は毎秒1件で、アプリを識別する User-Agent と出典表示が必要。クライアント側の入力補完は禁止。利用停止を求められたら止められる作りにする
- ジオコーダの比較: 国土地理院の地名検索 API は主に地理院地図からの利用を想定し、継続提供の保証がない。出典は https://github.com/gsi-cyberjapan/gsimaps/issues/29 の国土地理院の回答。Photon の公開 API は https://photon.komoot.io/ で公平な利用を求めるのみで、商用可否と出典表示は未確認。条件が明文化された Nominatim を採る

## 2. 使用しないデータ

| データ | 理由 |
|---|---|
| 各社の運行情報ページ・アプリ | 二次利用の許諾がない。Osaka Metro は無許可の二次利用を明示的に禁止 |
| 列車走行位置サービス | 再利用の許諾・API が確認できない |
| 非公式 API・スクレイピング | 権利が確認できない |
| 各社の時刻表 | 一括の再利用許諾がないものは除外し、個別に許諾した静的 GTFS は確認後に採用表へ追加 |
| ODPT 基本ライセンスのデータ | アプリ利用と再配布は別であり、取得 ZIP と復元可能な変換結果を公開リポジトリに含めない |
| HUB の神戸市バス GTFS-JP | 登録制であり、公開アプリと再配布の許諾範囲が未確認のため採用保留 |
| 各社のラインマーク・ロゴ | 商標の可能性。路線の色のみ使用する |
| 公共交通オープンデータチャレンジ限定のデータ | 同チャレンジ以外での利用不可 |
| 社内情報 | 規制値、規程、内部手順、実際の事故記録 |

## 3. 前処理上の注意

- 国土数値情報の版によっては、新しい駅（うめきた地下の大阪駅など）や事業者の変更（2025年4月の泉北高速鉄道の南海への合併）が反映されていない。使用する版を確認し、必要に応じて正規化する
- 鉄道データは駅も線で表現されている。駅の代表点は線の中点などで求める
- 国土数値情報の形は書き換えず、経路の網を組む段で列車の走り方を補う
- 阪急京都線は十三起点だが、列車は大阪梅田から出るので、大阪梅田から十三の区間を足す
- 補正は `packages/geo/src/corrections.ts` に置き、理由を 1 行で残す
- アメダスの10分値は気象庁のサイトで約9日分しか公開されない。デモ用に必要な期間がある場合は、取得した値を保存する

## 4. 出典表示

画面の地図の隅と、アプリ内の「このアプリについて」に以下を表示する。

```
地図: 国土地理院 / © OpenStreetMap contributors
鉄道データ: 「国土数値情報（鉄道データ）」（国土交通省）を加工して作成
駅の乗降客数: 「国土数値情報（駅別乗降客数データ）」（国土交通省）を加工して作成
気象データ: 気象庁
徒歩経路・到達範囲: © OpenStreetMap contributors のデータから Valhalla で計算
バス停の位置: 国土交通省「国土数値情報 バス停留所データ」2022年度版を加工して作成。ライセンス: CC BY 4.0
```

「このアプリについて」では、国土数値情報の各行に注に記したデータページの URL を添える。バス停の行には CC BY 4.0 の本文へのリンクも添える。バスルートの N07 は取り込んでいないので、その出典行は出さない。地名検索の結果は OpenStreetMap の出典表示で足りる。

## 5. 未確定事項

- 終電時刻: オープンなデータがない。利用者が時間の制約として入力する方式を基本とし、別の方法があれば検討する
- バス: GTFS データリポジトリを 2026-11-02 に確認した。京都府は0件、大阪府は1件だった。大阪シティバスや京都市バスなど都市部の主要事業者は登録がない。登録の多くはコミュニティバスなので対象外とする。各社が独自に公開するデータは未確認
- バス: 2026-11-05 の確認結果を次に記す
  > 国土数値情報の P11 と N07 は 2022 年度版が CC BY 4.0 で、位置と参考形状に利用できる。
  > 京都市バスと京都バスは ODPT に静的 GTFS があるが、基本ライセンスでは再配布できない。
  > 神戸市バスは登録制の HUB で GTFS-JP を配布し、公開アプリでの利用条件は未確認である。
  > GTFS データリポジトリの大阪と京都の件数は今回再確認できず、11-02 の記録と区別する。
- ジオコーダの切り替え先: Nominatim の公開インスタンスは予告なく利用を止められうる。その場合に Nominatim や Photon を自前で立てるかは未定

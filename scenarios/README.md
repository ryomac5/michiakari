# リプレイ用シナリオ

デモ、開発中の確認、振る舞いテストに使う架空のシナリオ。開発者本人が書く（エージェントは変更しない）。

- 1シナリオ1ファイル。書式は `_template.yaml`
- 発表文・掲示の文面は、典型的な表現を参考に自作する。実在の事故記録や公式発表文を転載しない
- `expectations` に、開発者が期待する振る舞いを数か所だけ書く。プロンプトやロジックを変えたときに振る舞いが壊れていないかを確かめる回帰テストになる
- `ground_truth` は架空の「実際にどうなったか」。デモの最後の比較に使う
- デモ用の優先シナリオ: 人身事故（終電間際）、大雨
